# Respawning Loot

**Respawning Loot** is a mod for **Zumbi Blocks 2** that adds respawning loot system with configurable respawn interval and optional randomization of loot types. By default, the mod respawns all loot every 5 minutes, and doesn't randomize the loot types.

## Installation

1. Make sure you have the latest version of **BepInEx 5** installed
2. Download the latest version of the mod from the [releases](https://github.com/tbv001/ZB2.RespawningLoot/releases) page
3. Copy the DLL file into the `plugins` folder of your BepInEx installation:

```
Zumbi Blocks 2 Open Alpha\BepInEx\plugins\RespawningLoot.dll
```

## Configuration

On first launch with the mod installed, a configuration file is generated at:

```
Zumbi Blocks 2 Open Alpha\BepInEx\config\com.theblackvoid.respawningloot.cfg
```
